# Лабораторная работа 2: Структура проекта (Плотникова)

## 1. Зачем нужен проект
Цель работы - навести порядок в файлах, сделать правильную структуру папок и проверить, как работает код после перезапуска.

## 2. Что где лежит:
`notebooks/lr01_runtime_order_plotnikova.ipynb` - мой готовый ноутбук из первой лабораторной.
`data/sample_text.txt` - первый файл с текстом для проверки.
`data/mini_corpus.tsv` - таблица с текстовыми карточками.
`docs/version_log.md` - файл, где записаны версии и шаги работы.

## 3. Инструкция по запуску
1. Зайти в Google Colab.
2. Загрузить ноутбук из папки `notebooks`.
3. Закинуть файлы из папки `data` прямо в сессию Colab, чтобы код их увидел.

## 4. Как проверялась воспроизводимость
Я сделала сброс среды через Restart runtime и запустила всё заново кнопкой Run all. Весь код отработал чисто, никаких ошибок NameError больше нет.

## 5. Ограничения
Код написан на базовом Python без сложных библиотек. Если забыть загрузить файлы данных в сессию, он выдаст ошибку, что файлы не найдены.
